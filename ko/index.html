ONE RULE. EVERY WORKING COPY.

커밋하지 않을 파일,
매번 걸러내지 마세요.

로그, 시스템 파일, 의존성 폴더. 프로젝트마다, 커밋할 때마다 같은 파일을 걸러내는 수고를 줄이세요.

설정 → 파일 필터에서 규칙을 설정하고 활성화하면 모든 작업 사본에 적용됩니다. 일치하는 항목은 목록에서 숨기며, 버전 관리에 추가하거나 커밋할 때도 범위를 확인합니다.

A CALMER WORKFLOW

매일 반복하는 SVN 작업,
더 편하게.

작업 사본을 열고 변경을 커밋할 때까지,
매일 쓰는 도구를 가까이에 두세요.

01 / WORKSPACES

프로젝트를 바꿔도 초안은 그대로

고정 사이드바에서 작업 사본을 전환하고 드래그로 정렬하세요. 세션 중 프로젝트별 커밋 초안, 선택 항목, 필터가 유지됩니다.

02 / REVIEW & COMMIT

준비된 변경만 커밋하세요

텍스트 Diff와 이미지 미리보기를 확인하고 파일 또는 디렉터리별로 커밋 범위를 선택하세요. Diff에서 돌아와도 선택과 커밋 메시지가 유지됩니다.

03 / LOCAL STASH

진행 중인 작업은 보관하고 전환하세요

파일 전체나 선택한 텍스트 변경 블록을 로컬에 보관한 뒤 원래 작업 사본에 복원하세요. 텍스트 패치를 복사하거나 내보낼 수도 있습니다.

04 / RENAME & MOVE

이름과 위치가 바뀌어도 이력은 그대로

속성에서 버전 관리 대상 파일과 디렉터리의 이름을 바꾸거나 이동한 뒤 새 경로로 이동합니다. 디렉터리 이동 커밋 시 원본과 대상 범위를 확인합니다.

05 / CONFLICTS

충돌 해결 방법을 직접 선택하세요

수동 해결한 내용을 유지하거나 로컬／저장소 버전을 선택하세요. 디렉터리와 트리 충돌은 먼저 정리하고 결과를 검토한 뒤 커밋합니다.

06 / REVIEW BEFORE REVERT

되돌리기 전에 영향 범위를 확인하세요

재귀 되돌리기 전에 영향받는 파일 트리를 확인하세요. 변경이 없고 전체 내용이 동일 리비전인 디렉터리를 과거 버전으로 복원해 로컬 변경으로 별도 커밋할 수도 있습니다.

빠른 시작 가이드 ↗
StoneSVN은 무료인가요?

네. StoneSVN은 MIT 라이선스의 무료 오픈 소스 프로젝트입니다. 소스 코드를 살펴보고 문제를 제보하거나 개발에 참여해 주세요.

Cornerstone에서 옮기려면 저장소를 이전해야 하나요?

아니요. StoneSVN은 로컬 SVN CLI를 사용해 기존 작업 사본을 열거나 원격 저장소를 체크아웃합니다. 처음 사용한다면 빠른 시작 가이드를 확인하세요.

병합과 충돌 해결을 지원하나요?

수동 해결한 내용이나 로컬／저장소 버전을 선택할 수 있습니다. 디렉터리와 트리 충돌은 먼저 정리한 후 해결로 표시하세요. 범용 Merge, Switch, 줄 단위 Blame UI는 아직 제공하지 않습니다.

어떤 언어와 테마를 지원하나요?

간체 중국어, 번체 중국어, 영어, 일본어, 한국어를 지원하며 설정에서 라이트 및 다크 테마를 선택할 수 있습니다.
