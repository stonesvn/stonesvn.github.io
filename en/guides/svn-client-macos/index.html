STONESVN · PRACTICAL GUIDES

An open-source SVN client for macOS, Windows and Linux

Project documentation · Checked against StoneSVN v1.1.2 · 18 October 2026

StoneSVN is a free, MIT-licensed Subversion desktop client for macOS, Windows and Linux. It uses your locally installed SVN command-line tool. Its main workflow is to open a working copy, review changes and choose the files or directories to commit.

What can I do with StoneSVN?

Keep multiple working copies in one project sidebar, inspect text diffs and image previews, browse commit and file history, and edit SVN properties. Commit drafts and selections stay with each project during the session. Local stashes can temporarily save selected text hunks when part of a change is not ready.

How do I get started on a Mac?

  1. Install an SVN CLI and check that svn --version --quiet works.
  2. Download the official installer for your chip: aarch64 for Apple Silicon or x64 for Intel.
  3. Open StoneSVN and let it detect SVN, or select the executable in Settings.
  4. Open an existing working copy or check out a repository. Review the changed files before selecting a commit.

macOS builds are ad-hoc signed and are not notarized. First-launch details are in the macOS distribution guide. Managed Macs may require help from your IT administrator.

Can I use an existing SVN working copy?

Yes. Select your existing local working copy; there is no StoneSVN-specific repository conversion. Repository access still depends on your SVN installation, credentials and network. Before moving an important workflow, test on a separate working copy and keep a backup of uncommitted work.

Does it replace every feature of another SVN client?

StoneSVN is useful for day-to-day review, selected commits and local stashing. General Merge, Switch and line-by-line Blame interfaces are not available. Use another SVN client or the command line for those tasks. Local stashes are application-managed and do not interoperate with native SVN shelves.

Where does the project come from?

StoneSVN is developed from OrcaSVN, using Tauri, Rust and Vue 3. Source code and installers are public. This guide describes StoneSVN's own behavior and does not claim performance advantages over other clients.
