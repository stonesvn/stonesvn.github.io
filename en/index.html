ONE RULE. EVERY WORKING COPY.

Files you never commit.
Out of your way.

Logs, system files, dependency folders. Stop filtering the same noise in every project and before every commit.

Configure and enable rules in Settings → File Filters. Every working copy shares them. Matching items stay out of the list, with scope checks when adding files and committing.

Use names, paths, and wildcards. StoneSVN applies these filters locally without changing the repository’s SVN ignore properties.

A CALMER WORKFLOW

Everyday SVN,
with less friction.

From opening a working copy to committing changes,
keep everyday tools within reach.

01 / WORKSPACES

Switch projects. Keep your draft.

Switch working copies in a persistent sidebar and drag to reorder. Commit drafts, selections, and filters stay with each project during the session.

02 / REVIEW & COMMIT

Commit just what is ready.

Review text diffs and image previews, then select files or directories to commit. Your selections and commit message remain when you return from a diff.

03 / LOCAL STASH

Pause work. Stash it for later.

Stash whole files or selected text hunks locally, then restore them to the original working copy. Copy or export text patches when needed.

04 / RENAME & MOVE

Rename and move. Keep the history.

Rename or move versioned files and directories in Properties, then jump to the new path. Directory move commits validate the full source and destination scope.

05 / CONFLICTS

Choose how to resolve conflicts.

Keep manually resolved content, or choose the local or repository version. Organize directory and tree conflicts first, then review and commit the result.

06 / REVIEW BEFORE REVERT

See the scope before reverting.

Review the affected file tree before recursive revert. You can also restore clean, complete, single-revision directories to a historical revision as local changes for a separate commit.

GOOD TO KNOW

A few things to know.

Quick start guide ↗
Is StoneSVN free?

Yes. StoneSVN is free and open source under the MIT license. Explore the code, report issues, or contribute to the project.

Moving from Cornerstone? Do I need to migrate?

No. StoneSVN uses your local SVN CLI to open existing working copies or check out remote repositories. Start with the quick start guide if you are new to the app.

Does it support merging and conflict resolution?

Conflict actions support manually resolved content or the local/repository version. Organize directory and tree conflicts before marking them resolved. General Merge, Switch, and line-by-line Blame interfaces are still unavailable.

Which languages and themes are available?

The app supports Simplified Chinese, Traditional Chinese, English, Japanese, and Korean, with light and dark themes available in Settings.
