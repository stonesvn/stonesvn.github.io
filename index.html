01 / WORKSPACES

Many projects. One place.

Switch working copies in a persistent sidebar and drag to reorder. Commit drafts, selections, and filters stay with each project during the session.

02 / REVIEW & COMMIT

Review first. Commit next.

Review text diffs and image previews, then select files or directories to commit. Your selections and commit message remain when you return from a diff.

03 / LOCAL STASH

Pause work. Pick it up later.

Stash whole files or selected text hunks locally, then restore them to the original working copy. Copy or export text patches when needed.

GOOD TO KNOW

A few things to know.

Quick start guide ↗
Is StoneSVN free?

Yes. StoneSVN is free and open source under the MIT license. Explore the code, report issues, or contribute to the project.

Do I need to migrate my SVN repository?

No. StoneSVN uses your local SVN CLI to open existing working copies or check out remote repositories. Start with the quick start guide if you are new to the app.

Does it support merging and conflict resolution?

The current version has no general Merge, Switch, or conflict Resolve UI. Use another SVN client or the command line for these operations, then refresh StoneSVN. File history does not include line-by-line Blame.

Which languages and themes are available?

The app supports Simplified Chinese, Traditional Chinese, English, Japanese, and Korean, with light and dark themes available in Settings.
